# مدرسه جادویی من 🌈 — Flutter project

پروژه‌ی آموزشی فارسی با پروفایل چند دانش‌آموز، فهرست نشانه‌ها، پخش صوت فارسی (در صورت پشتیبانی گوشی)، تمرین نوشتن با انگشت و ذخیره‌ی ستاره‌ها روی همان دستگاه.

## نیازمندی‌ها
- Flutter SDK پایدار (پیشنهاد: نسخه‌ی پایدار روز)
- Android SDK و Java 17
- اتصال اینترنت برای دریافت پکیج‌ها و ابزارهای Gradle در اولین ساخت

## اجرا و ساخت APK
از ریشه‌ی پروژه:

```bash
flutter pub get
flutter create --platforms=android .
flutter build apk --release
```

فایل خروجی معمولاً در این مسیر ساخته می‌شود:

`build/app/outputs/flutter-apk/app-release.apk`

دستور `flutter create --platforms=android .` فایل‌های استاندارد پلتفرم و Gradle Wrapper را مطابق نسخه‌ی Flutter نصب‌شده تولید/تکمیل می‌کند. این محیط به Flutter SDK دسترسی نداشت؛ بنابراین APK در اینجا کامپایل یا روی دستگاه آزمایش نشده است.

## امکانات فعلی و محدودیت‌ها
- پروفایل‌ها و پیشرفت هر دانش‌آموز روی همان دستگاه ذخیره می‌شوند.
- فهرست نشانه‌ها به ترتیب جدول برنامه‌ریزی استخراج‌شده از کتاب نگارش تنظیم شده است؛ متن کتاب‌ها بازنشر نشده است.
- صدا با موتور TTS گوشی پخش می‌شود؛ کیفیت و دسترسی صدای فارسی به تنظیمات دستگاه وابسته است.
- صفحه‌ی نوشتن، بوم تمرین آزاد است و هنوز تشخیص خودکار دست‌خط یا نمره‌دهی ندارد.
- گزینه‌های بازی و املا در این نسخه‌ی اولیه پیاده‌سازی نشده‌اند.
- تصویرهای اختصاصی عروسک‌ها هنوز افزوده نشده‌اند؛ از ایموجی‌های تزئینی استفاده شده است.

## نکته درباره ساخت با موبایل
برای کامپایل APK به محیطی نیاز است که Flutter SDK و Android SDK را اجرا کند. این ZIP سورس پروژه و تنظیمات Android را در بر دارد؛ به‌تنهایی APK نیست.
